# 基金智能分析Agent系统

基于多因子决策引擎的基金分析系统，整合技术面、舆情面、基本面、市场环境四维度数据，输出结构化投资建议。

## 解决什么问题

个人投资者整合基金信息时，需要在多个平台之间切换（看净值、看新闻、算指标），效率低且容易遗漏关键信息。本项目通过 Agent 架构，输入基金代码即可输出完整的分析报告。

## 技术栈

- **数据获取**：AkShare（A 股基金数据接口）
- **大模型**：SenseNova（商汤），用于新闻情感分析
- **决策引擎**：多因子加权模型（技术35% + 舆情35% + 基本面20% + 市场环境10%）
- **报告输出**：Markdown / JSON

## 核心模块

```
agent/
├── core.py          # Agent 核心，编排三阶段流程
├── decision.py      # 多因子决策引擎
└── tools/
    ├── data_fetcher.py   # AkShare 基金数据获取
    ├── news_crawler.py   # 新闻爬虫 + 基础情感分析
    └── sentiment.py      # LLM 深度情感分析
```

## 三阶段流程

1. **数据获取**：基金基本信息、历史净值、持仓明细
2. **信息处理**：技术指标计算、新闻抓取、情感分析
3. **决策输出**：多因子评分、风险评估、投资建议

## 快速开始

```bash
pip install -r requirements.txt
python main.py
# 输入基金代码（如 110011）即可生成分析报告
```

## 决策引擎参数

- 买入阈值：综合得分 ≥ 65
- 持有阈值：45 ≤ 得分 < 65
- 卖出阈值：得分 < 30
- 最大建议仓位：30%
- 最小置信度：0.6

## 输出示例

报告包含：综合评分、投资建议（买入/持有/卖出）、建议仓位、目标价位、止损止盈、风险等级、多因子得分详情、关键发现、决策推理过程。

## 风险提示

本项目仅用于学习和研究，不构成任何投资建议。
