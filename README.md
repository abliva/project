# AIGC 实战项目集合

> 作者：蔡俊鸿 | 广东理工学院 人工智能专业
>
> 本仓库收录 5 个 AIGC 方向的实战项目，涵盖 RAG 检索增强、Agent 工具编排、计算机视觉、后端全栈、数据采集可视化五大方向。

## 项目列表

| # | 项目 | 技术栈 | 解决的问题 |
|---|------|--------|-----------|
| 01 | [RAG智能问答助手](./01-RAG智能问答助手) | SenseNova / Flask / SSE | 大模型幻觉问题 |
| 02 | [基金智能分析Agent系统](./02-基金智能分析Agent系统) | AkShare / SenseNova / 多因子决策 | 基金信息整合分析 |
| 03 | [多功能AI智能助手](./03-AI多功能智能助手) | ReAct / BaseTool / 动态注册 | 复合任务自动执行 |
| 04 | [数据采集可视化后台系统](./04-数据采集可视化后台系统) | Flask / MySQL / LRU缓存 / ECharts | 数据采集到可视化全链路 |
| 05 | [无人机火情监测系统](./05-无人机火情监测系统) | YOLOv8 / OpenCV / Tkinter | 人工巡检效率低 |

## 技术能力

- **大模型应用**：RAG 架构、Agent 工具调用、Prompt Engineering、ReAct 模式
- **后端开发**：Flask、MySQL、SQLite、RESTful API、SSE 流式输出
- **计算机视觉**：YOLOv8 目标检测、OpenCV 图像处理、误检过滤
- **工程能力**：模块化设计、自实现 LRU 缓存、连接池、多线程爬虫

## 环境要求

- Python 3.8+
- 各项目依赖见对应 `requirements.txt`

## 使用方式

每个项目都是独立可运行的，进入对应目录查看 README 即可。
